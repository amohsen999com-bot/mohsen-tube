# محسن تيوب (Mohsen Tube — Next.js + TypeScript + SQLite FTS5)

نسخة مبنية بـ **Next.js (App Router) + TypeScript + Tailwind CSS + SQLite (FTS5)**، جاهزة بالتشغيل المباشر وبدون أي علامات أو شعارات يوتيوب على المشغّل.

## طريقة التشغيل السريعة (Windows)

1. تأكد من وجود **Node.js 22.5+** (أو Node.js 24) على الجهاز: https://nodejs.org
2. اضغط مرتين على **`start.bat`** (أو شغّل الأوامر بالأسفل).
3. افتح المتصفح على: **http://localhost:3000**

## التشغيل من الـ Terminal (ويندوز / لينكس / ماك)

```bash
npm install
npm run dev
```

للإنتاج (Production):

```bash
npm install
npm run build
npm start
```

## محتويات المشروع

- `data/mohsen.db` — قاعدة بيانات SQLite جاهزة ومفهرسة بـ FTS5 (تحتوي على 13,414 فيديو مختار، و100,589 فيديو في فهرس البحث، و246 قناة، و189 سلسلة، والتعليقات).
- `src/` — كود الواجهة والخوارزميات والسيرفر (Next.js + TypeScript).
- `scripts/seed-from-zip.ts` — سكريبت إعادة بناء قاعدة البيانات لو احتجت تحديثها مستقبلاً (`npm run seed`).
- `tests/mohsen-tube.test.ts` — اختبارات البحث والبيانات ومواقيت الصلاة (`npm test`).

## الجديد في التحديث ده

- **الخوارزمية:** "مزاجك دلوقتي" (ذاكرة جلسة بنص عمر 40 دقيقة)، و"اللي اتفرجوا على ده" (`/api/videos?related_for=`؛ لو مفيش ترشيحات يوتيوب للفيديو بنستخدم المحتوى الشبيه)، و"جديد من قنواتك" (آخر 21 يوم)، وطبقة المدى البعيد (`src/lib/client/growth.ts`: التوازن، السلّم، العلم ← العمل، ضد الإدمان، المواسم). وتسجيل الكروت اللي اتعدّت من غير ما تتفتح.
- **ترشيحات صفحة الفيديو:** 3 بالكتير من نفس القناة/الموضوع، والباقي من خوارزمية "مقترح لك".
- **المشغّل:** مشغّل واحد طول الجلسة (`loadVideoById`)، فالفيديو اللي بعده بيشتغل فورًا من غير شاشة سودا. `?s=` و`?s=&e=` بيتقروا مع تحميل الفيديو. سياق السلسلة (`nt_pl`).
- **حسابك:** مزامنة بين الأجهزة عن طريق Supabase (اختياري) + نسخة احتياطية تتنزّل وترجع. انسخ `.env.example` لـ `.env.local`، وضيف عنوان الموقع في Supabase ← Authentication ← URL Configuration ← Redirect URLs.
- **الأمان:** أكواد غرف "اتفرج مع صاحبك" وتوكناتها بتتعمل على السيرفر، والتعديل محتاج توكن، وفيه حد للطلبات. إجابات المشاهدين من قائمة مسموحة بس، وصوت واحد لكل شخص.
- لو عندك ملف `related.json` من الموقع القديم: `node --experimental-strip-types scripts/import-related.ts path/to/related.json`.
- **ملحوظة للنشر:** حدود الطلبات بتعتمد على `X-Forwarded-For`، فلازم السيرفر يبقى ورا proxy (Nginx/Cloudflare) بيكتب الهيدر ده بنفسه.
